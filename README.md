# PUDLA снаружи

Раз в минуту проверяет, открывается ли https://pudla.app, с серверов GitHub, вне хостинга.
Если приложение не отвечает 5 минут подряд, сообщение уходит в служебный канал. Пока сбой идёт, раз в час
приходит напоминание, после сбоя — «снова работает».

Файлы `state` и `heartbeat` пишет сама проверка: что она видела в последний раз, и отметка раз в неделю,
чтобы GitHub не выключил расписание.
